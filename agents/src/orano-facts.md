# ORANO: facts for directory listings

- Product name: ORANO (also written "Orano AI")
- Website: https://oranoai.com
- Category: Productivity (AI productivity tools)
- Platforms: mobile app on iOS and Android
- Contact email for listings and verification: hello@oranoai.com
- One-liner: ORANO turns saved Reels, videos and links into useful projects with clear next steps, and makes that context readable by your own AI agent.

What it does: share a Reel, video, article, PDF or repo to ORANO. It reads the speech, frames, on-screen text and source
context, then turns the save into a summary, key takeaways and a project with ordered next steps. Saves stay searchable.

Differentiators:
1. It understands the content itself (speech, video frames, on-screen text), not just the link.
2. Each save becomes a project with ordered next steps, not only a summary or a bookmark.
3. The user's own AI agent (for example ChatGPT, Claude or Cursor) can read their saved context through a personal, read-only MCP connection.
